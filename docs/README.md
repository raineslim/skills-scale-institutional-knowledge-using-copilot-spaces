# OctoAcme Project Management Docs

This directory contains the project management guidance used by OctoAcme. It provides a concise, shareable set of processes for planning, delivery, communication, risk management, release, and continuous improvement.

## Project management process overview

OctoAcme uses a lightweight, iterative project management approach designed to keep stakeholders aligned and projects moving with clear ownership and measurable progress.

- Initiation: validate the business need, align stakeholders, and create the project one-pager and initial plan.
- Planning: define scope, milestones, backlog, dependencies, and the definition of done.
- Execution: run standups, track progress, manage blockers, and keep work visible through the delivery cycle.
- Risk and communication: identify risks, assign owners, escalate as needed, and share regular status updates.
- Release and deployment: verify readiness, coordinate rollout, and document rollback or mitigation steps.
- Retrospective and improvement: capture learning, convert it into action items, and improve the process over time.
